# 🎵 МемоБред

Вечериночная игра: собери свой бред из мемов.  
Наследник механики «Звукварь» / «МП3-бред», но в браузере.

- **Один хост** открывает экран, **все остальные** — с телефонов.
- **Никаких установок** — заходишь по ссылке, вводишь код комнаты.
- **Работает на Termux и Linux** — один скрипт запуска.
- **Свои мемы** — кладёшь mp3 в `memes/`, играешь.

---

## Как играется

1. Один игрок открывает игру, создаёт комнату, получает **код из 4 букв**.
2. Остальные заходят по этому коду с телефонов.
3. Каждый раунд **судья** (по кругу) выбирает задание из 3 вариантов.
   Например: *«Звук, который издаёт твой начальник, когда злится»*.
4. Все остальные получают **руку из 7 мемов** и отправляют **комбо из 2**.
5. Судья вслепую выбирает лучшее комбо. Раскрытие, счёт, следующий раунд.
6. Партия длится **N раундов**, где N = число игроков. Каждый по разу судья.
